Что происходит с сообщением

Один адресат. Несколько возможных маршрутов.

MeshGram не отправляет сообщение в открытом виде. Приложение ищет подходящий путь, передаёт зашифрованный пакет и проверяет, что он дошёл именно до нужного получателя.

01 / FIND
⌁

Находим своих

Телефон сканирует BLE-эфир и видит только устройства, которые участвуют в MeshGram. Чужие телефоны не становятся скрытыми ретрансляторами.

02 / WRAP
◌

Запечатываем пакет

Текст и файлы шифруются для конкретного адресата. Промежуточный узел видит технические данные, TTL и маршрут, но не содержимое.

03 / DELIVER
↗

Доставляем точно

Рядом пакет идёт по BLE mesh. Если адресат далеко или узлов пока мало, включается зашифрованный интернет-резерв, если пользователь его разрешил.

Важно о дальности BLE не создаёт связь на километры сам по себе: дальний маршрут появляется только через реальные MeshGram-узлы или интернет-резерв.

01

BLE-приоритет

Когда рядом есть устройства MeshGram, сообщения идут по локальной mesh-сети. Приложение не отключает интернет в телефоне и не вмешивается в другие приложения.

02

Читают только участники

Кадры проходят через узлы как зашифрованные конверты. Relay видит только технический пакет, не текст и не файлы.

03

Локальное хранение

История и очередь доставки остаются в защищённом хранилище устройства. Для миграции предусмотрен зашифрованный экспорт.

Работает ли MeshGram без интернета?

Да, для близких устройств с MeshGram может использоваться BLE mesh. Интернет нужен только для разрешённого дальнего резерва и не отключается для других приложений.

Могут ли чужие телефоны передавать мои сообщения?

Нет. В текущей модели ретрансляторами являются только устройства, на которых установлен MeshGram и включена соответствующая функция. Случайные телефоны не используются скрытно.

Что видит промежуточный узел?

Технические сведения, необходимые для маршрута: идентификатор пакета, TTL и служебные признаки. Содержимое сообщения и файлов должно оставаться зашифрованным для адресата.

Когда выйдет версия для iOS?

iOS-клиент находится в дорожной карте. Срок будет объявлен после отдельного цикла разработки и тестирования. Поддержка проекта помогает ускорить этот этап, но не заменяет тесты.
