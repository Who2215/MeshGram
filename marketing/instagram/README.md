# MeshGram Instagram package

Готовый комплект для запуска рекламы MeshGram в Instagram:

- `MeshGram-instagram-feed-1080x1350.png` — пост 4:5 для ленты.
- `MeshGram-instagram-story-1080x1920.png` — Stories/Reels cover.
- `caption-ru.txt` — подпись с призывом к действию и хэштегами.

## Рекомендованный порядок

1. Для ленты использовать изображение 4:5 и подпись из `caption-ru.txt`.
2. Для Stories использовать вертикальный вариант, добавить ссылку на сайт и стикер «Попробовать».
3. Для Reels использовать `site/assets/meshgram-teaser-v2.mp4`, а вертикальный постер оставить обложкой.
